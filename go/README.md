# Лабораторная работа №2 — Go

Модуль Go: `lab2` (Go 1.20).

## Структура проекта

- `lab1/` — структуры данных из лабораторной работы №1 на Go:
  - `Stack` — стек;
  - `Strarray` — динамический массив строк;
  - `SNode` — односвязный список;
  - `DNode` — двусвязный список;
  - `Queue` — очередь;
  - `CompleteBinaryTree` — полное бинарное дерево.
- `task1/` — восстановление XML, использует `lab1.Stack`.
- `task2/` — множество с прямым адресованием и хранением элементов в файле.
- `task3/` — разбиение множества на группы равной суммы.
- `task4/` — генерация всех подмножеств, использует `lab1.Strarray`.
- `task5/` — бинарное дерево поиска и вычисление высоты.
- `task6/` — линейное апробирование, двойное хеширование и поиск самой длинной подстроки без повторов.
- `task7/` — LRU-кэш, использует `lab1.DNode` и двусвязный список.

## Сборка и запуск

Из каталога `go/`:

```bash
go test ./...
go build ./...
```

Каждое задание запускается отдельно:

```bash
go run ./task1
go run ./task2 --file set.txt --query "SETADD 10 SET_AT 10"
go run ./task3
go run ./task4
go run ./task5
go run ./task6 6.1
go run ./task6 6.2
go run ./task7
```

Задание 2 также может читать команды из стандартного ввода, если параметр `--query` не указан. При использовании `--file` множество загружается из файла перед выполнением команд и сохраняется обратно после выполнения.

## Соответствие C++ версии

Ввод, алгоритмы, порядок обхода и текстовый вывод Go-версии приведены к соответствующим реализациям C++ из каталога `cpp/`. Для задания 6.2 обе версии выводят длину и найденную подстроку в формате `3 (abc)`. Для задания 7 результаты всех команд `GET` накапливаются и выводятся одной строкой после обработки всех запросов.
